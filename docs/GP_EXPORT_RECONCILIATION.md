# GP-annotated export reconciliation against PocketBase

Use `notebooks/cfps_gp_export_pocketbase_reconciliation_colab.ipynb` in Google Colab to compare the frozen `clusters_designs.json` against a complete authenticated, read-only PocketBase `cfps_designs` fetch. The comparison uses immutable PocketBase IDs, canonical target protein, and exact reagent dispensing volumes (nL; 1e-6 nL formatting tolerance). It reports missing, new, and modified records and excludes nonexperimental records from the eligible candidate pool.

**Do not assume the annotated export is raw PocketBase data.** It contains GP forecasts, groups, and selection roles derived from a historical snapshot. A changed candidate recipe, new ID, or deleted ID cannot safely inherit those historical GP-derived fields. Therefore the notebook emits `clusters_designs_verified.json` **only if the entire experimental candidate pool matches**; this is a byte-for-byte verified copy, not a regenerated model. If discrepancies exist, the notebook emits `pocketbase_snapshot.json` for `INPUT_SOURCE = "pocketbase_snapshot"` in the main Colab notebook, which runs model-free analysis only. Regenerating GP forecasts, clustering, and roles requires the original GP modeling workflow and its data; this utility cannot do that.

Outputs: `reconciliation_report.json`, `pocketbase_snapshot.json`, optional `clusters_designs_verified.json`, and `SHA256_MANIFEST.json`, packaged as `cfps_reconciliation_private.zip`. Treat all outputs as **private**; do not commit them or distribute them publicly. PocketBase credentials are supplied through Colab Secrets or a secure password prompt, not included in outputs. The default database URL is configurable and must be verified for your authorized environment. Live authentication and server-side permissions have not been tested in this source release.

**Suggested workflow:** Run the reconciliation notebook first; inspect the report. If `gp_refresh_safe` is true, use the verified annotated copy for all three selection modes. Otherwise, use the unannotated PocketBase snapshot for a current model-free analysis and separately rerun the original GP modeling workflow if a current GP-informed comparison is required.
